纯前端浏览器端音序器（Beat Maker）

简介

PawBeats 是一款基于 Web Audio API 的浏览器端音乐创作工具。所有音频合成、采样播放、效果器处理均在本地完成，无需后端服务，打开浏览器即可使用。

支持旋律编辑、鼓机编排、效果器叠加、音频可视化、工程保存与分享等功能，同时内置了猫咪叫声、狗狗叫声、机器人音效等趣味采样。

快速开始

直接在浏览器中打开 `index.html` 即可使用，无需安装任何依赖。


使用说明

1. 选择素材：点击左侧预设图标栏选择分类（合成器/猫叫/狗叫等），再点击素材库中的 8 个槽位之一
2. 放置音符：在旋律网格中点击格子放置/切换音符力度（空 → 轻 → 中 → 重 → 移除）
3. 编排鼓点：在鼓机网格中同样方式放置鼓点
4. 播放：按空格键或点击 ▶ 按钮开始播放
5. 调节参数：使用控制面板调节 BPM、音量、Swing、波形等
6. 保存工程：点击工具栏 💾 按钮保存当前工程
7. 导出音频：点击工具栏 📥 按钮导出为 WebM 文件
